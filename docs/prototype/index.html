📐 设计原则 · Design Principles

1. 海报即信息 · 一张海报能传达 80% 的元数据(标题/评分/4K 标签/进度条),详情页是次级入口。
2. 焦点一致性 · 三端共享品牌色与组件语言,但根据设备特性分化:Admin 用 Element Plus 数据密度优先 · Web 用 Hero+卡片流 · TV 用 10 英尺大字号+焦点环。
3. 状态可见 · 转码 / 下载 / 刮削 / 入库 任何异步任务都展示进度数字而非 spinner,避免"不知道在干嘛"。
4. Profile 隔离 · 儿童模式自动隐藏 is_adult 内容,所有请求带 X-Profile-ID,缓存按 Profile 前缀隔离。
5. 暗色影院级 · 三端统一暗色背景,降低观影干扰,海报色彩更突出。
6. 深链优先 · 详情页和播放器都支持 /player/:id?episode=:eid 深链,直接跳到指定季/集并自动播放。
